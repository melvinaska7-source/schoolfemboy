# SchoolFemboy Runaway — Android/Godot prototype

Проект сделан под Godot 4.5.1 и рассчитан на сборку **без ПК пользователя**: исходники загружаются в GitHub, GitHub Actions собирает APK.

## Быстрый запуск
1. Создай пустой GitHub-репозиторий.
2. Загрузи **все содержимое этой папки** в репозиторий.
3. Открой вкладку Actions → `Build Android APK`.
4. Запусти workflow вручную или сделай push в `main`.
5. После сборки скачай artifact `schoolfemboy-runaway-apk` и достань APK.

## Что уже реализовано
- главное меню: Играть / Настройки / Познакомиться / Как играть;
- таймер 5/10/15 минут;
- переключатель музыки;
- первый этаж в 3D, собранный по предоставленному плану в виде приблизительного игрового прототипа;
- первый-person управление;
- мобильный джойстик, свайп для обзора и кнопка прыжка;
- PNG-учителя как 2D-спрайты в 3D;
- Литричка, Тишков и Лихачева с базовым патрулированием, слухом, зрением и погоней;
- при начале погони остальные учителя скрываются;
- Био-Радар;
- захват Лихачевой с 30-секундным окном и «БЕГИ!!!»;
- захват Литричкой с мини-игрой из 10 кругов;
- проигрыш/победа и звуки из исходного архива;
- закрытые лестницы как границы первой версии;
- современные парты как простые укрытия.

## Важно
Это именно **первый играбельный прототип**, а не финальная реконструкция школы. План в исходных материалах содержит дорисованные пользователем элементы; неизвестные помещения намеренно не восстанавливаются «из головы». Геометрия пока приблизительная и должна быть уточнена после сверки с фотографиями.

## Известное ограничение
В этой версии Андрохак пока представлен логикой спасения/контентом меню, а его полноценная физическая NPC-сцена с отдельной моделью ещё не доведена до финала. Это следующий очевидный шаг.
